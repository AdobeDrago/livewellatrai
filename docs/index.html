Residuals / not verified

  • Footer pixels: the text paragraphs render 1px lower than the source's, although their layout boxes match (4181.72 vs 4181.73 page Y at 1280). Within the footer, the shift covers only the text. The result depended on the footer's page position (it passed at 1280 when the page was taller). Not fixed; stop rule.
  • The contacts list's open state is not gated (per intake). It was checked by clicking once at 1440: 19 vendor tiles and the callout appear.
  • Only 1440 and 1280 were measured. Mobile/tablet widths, hover states and the "Benefit Guides" dropdown are not verified.
  • The source ships no Aeroport webfont, so both sides render the fallback sans-serif.
  • The empty "Learn more on Employee Central." link has an empty href on the source too; it is kept as authored.

Rules from the repo's AGENTS.md

  • Markup comes from the backend: fetch /path.plain.html before writing a block.
  • buildAutoBlocks rewrites content before a block runs; authors omit and add cells, so decorate defensively.
  • Scope CSS to .blockname; -wrapper and -container are section classes.
  • A PR without a {branch}--livewellatrai--AdobeDrago.aem.page/{path} link is rejected.
  • Merging main ships code; content is previewed and published separately in DA.
  • All committed files are served — use .hlxignore for anything that should not be.

Authoring workflow in DA.live

  1. Open da.live/#/adobedrago/livewellatrai and edit the document.
  2. Preview from DA (or use the Sidekick) and check https://main--livewellatrai--adobedrago.aem.page/.
  3. For a code change, branch from main, push, and open the PR with the <branch>--livewellatrai--adobedrago.aem.page link.
  4. Publish content to .aem.live after QA.
